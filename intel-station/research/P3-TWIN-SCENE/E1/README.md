Status vocabulary: MEASURED (from the recordings in this pass or the cited file); DERIVED (computed from measured or config values); UNRESOLVED (methods disagree, so no single value is usable); LOW (usable with a stated error); NOT MEASURED; ASSUMED (not measured, flagged).

## Frames

- Base frame (kin.py), mm. MAT_Z = -38.3 mm is the TCP z at mat contact (app/tools/kin.py:24).
- Mat frame (depth data): x image-right, y toward base. No camera-to-base extrinsics exist here, so depth positions cannot be placed in the base frame. Only separations are frame-free.
- The MJCF is in metres, base frame. It contains the scene only (no arm).
