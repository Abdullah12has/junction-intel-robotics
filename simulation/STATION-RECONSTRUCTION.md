# Camera-based station reconstruction — 14 November 2026

The current sorting scene is based on the user's screenshot and fresh 640×480
frames captured from both Intel RealSense cameras through Studio's supported
camera preview WebSocket. Three frames were received from each feed; the last
frame was retained locally. No runtime robot sessions existed during inspection.
No serial device, motor control, calibration, camera settings, or running service
was changed. Preview sockets were closed after capture.

Private source frames and capture metadata are in ignored `outputs/reference/`:
`243622061421.jpg` (overhead) and `243722064316.jpg` (close pickup-area view).
Do not commit or publish these images; they contain the real workspace.

## Run and controls

```sh
uv run python view.py --scene sorting --layout reference
```

The viewer starts in the overhead camera. **C** cycles overhead → close view →
free orbit. **V** returns to the reference object arrangement; **R** generates
a new randomized layout. **B/G** choose the requested bowl. The instruction
and controls appear inside the viewer. Camera snapshots are generated by
`uv run python smoke.py --scene sorting --layout reference` in `outputs/sorting/`.

## Limits and parameter provenance

This is a visual reconstruction, **not a calibrated digital twin**. Camera
positions/FOV, bowl dimensions/locations, arm pose, mat/prop sizes and lighting
are hand-fitted approximations. Intrinsics, distortion, extrinsics, action-unit
mapping and reachable successful grasps have not been measured or validated.
The simulator's initial arm pose is a model-only visual choice, never hardware
homing/calibration. Do not use this scene to infer safe physical trajectories.

The confirmed 2×2 width supports a DUPLO-style scale. Modeling values are
31.8×31.8×19.2 mm (2×2) and 63.8×31.8×19.2 mm (2×4), with 16 mm stud pitch.
Only the approximate 2×2 width was confirmed physically; other values follow
the nominal doubled LEGO grid. Hollow studs use an estimated 9.6 mm outer
diameter, 6.6 mm inner diameter and 3.6 mm height. Those details and provisional
6 g / 12 g masses still need measurement. LEGO describes DUPLO as twice the
regular brick scale: https://www.lego.com/en-gb/service/help-topics/article/comparing-lego-bricks-plates-and-duplo-bricks

Hollow studs are visual ring meshes with simplified solid-cylinder collisions;
underside cavities and clutch/snapping are not modeled. Bowl interiors use a
floor and separate convex wall sectors so the collision hull does not fill the
cavity. Reward still requires a lifted, released target block settled near the
requested bowl's floor center, not contact with its rim.

50 demonstrations remain an initial dataset, with exact color/destination
instructions. No expert, synthetic demonstrations, policy training, hardware
movement, or successful pick-and-place has been added by this reconstruction.
