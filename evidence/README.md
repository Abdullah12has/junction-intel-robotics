# Evidence index

Artifacts are dated snapshots, not live telemetry. The [submission overview](../docs/SUBMISSION.md) states the supported claims and limitations. Older inspection-task results must not be presented as blue-plate task success.

| Evidence | What it supports |
|---|---|
| [Dataset curation](blue-plate-curation/) | Data preparation and split review |
| [Campaign preparation](blue-plate-campaign/) | Experiment configuration and validation |
| [Launch records](blue-plate-launch/) | Real-data GPU launch and preflight snapshots |
| [Queue sharding](blue-plate-sharding/) | Split-host deployment and partition validation |
| [Action-limit audit](action-limit-audit/) | Dataset statistics, CPU parity and bounds replay |
| [Frozen-policy improvement](frozen-policy-improvement/) | Offline visual-feedback development evidence |
| [Historical station status](STATUS.md) | Earlier inspection, export and physical motion checks |

Machine identifiers and dates identify the original observations; they do not establish current availability. No checkpoint weights or demonstration videos are included here. Successful offline checks or completed robot motion do not establish successful pick-and-place.
